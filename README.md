Если ты хочешь просто попробовать игру, ничего самому собирать не нужно.

Готовые сборки различных версий находятся во вкладке **[Releases](https://github.com/Dimarik5/smeshario-ios/releases)**.

> [!IMPORTANT]
> Приложение **не подписано**. Перед установкой его необходимо подписать с помощью одного из инструментов ниже.

После скачивания файла его нужно установить через:

- SideStore (проверено)
- AltStore (должно сработать)
- или прочие подобные утилиты

# 📖 Предыстория

Впервые эта игра появилась в 2025 году как обычный университетский проект трёх студентов. Сначала была создана версия на Java для одной дисциплины, а затем игра была перенесена на **Clickteam Fusion 2.5** для другой.

Меня часто посещала мысль:
> **"Эх, вот бы сделать чисто для себя какую-нибудь программку или игру на айфон. Но я не хочу для этого покупать Mac или арендовать облачный."**

И вот однажды, копавшись в публичных репозиториях GitHub и в очередной раз спрашивая ChatGPT, могу ли я без Mac собрать приложение для своего айфона, я узнал, что такая возможность есть и это абсолютно бесплатно и в какой-то степени безлимитно!

После десятков ~сообщений ChatGPT~ неудачных сборок, небольшого изучения устройства Xcode-проектов и GitHub Actions, а также особенностей сборки iOS-приложений у меня получилось настроить автоматическую сборку неподписанного .ipa файла прямо в GitHub.

Возможно, этот репозиторий вдохновит тебя на создание чего-нибудь своего)

> [!TIP]
> Если тебе интересна не столько сама игра, сколько процесс сборки iOS-приложения без Mac, можешь сразу перейти к разделу **[⚙️ Техническая часть](#%EF%B8%8F-%D1%82%D0%B5%D1%85%D0%BD%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B0%D1%8F-%D1%87%D0%B0%D1%81%D1%82%D1%8C)**.

# 🎮 Об игре

**«Смешарио»** - это небольшой бесконечный автораннер.

Игрок выбирает одного из 4 персонажей и его цель - пробежать как можно дальше, перепрыгивая препятствия и собирая предметы. Чем дальше получится забраться и чем больше предметов будет собрано, тем больше очков можно заработать и тем больше персонажей открыть.

Каждый герой пришёл в огород Копатыча со своей целью:

- 🥕 **Крош** собирает морковь
- 🌵 **Ёжик** - кактусы
- 📜 **Бараш** - потерянные листы со своими стихами
- 🍬 **Нюша** - конфеты

У каждого персонажа есть уникальная фраза, рассказывающая о том, зачем он бегает по огороду. Фразы были озвучены нами, а затем голос был изменён с помощью нейросети. Голосовые модели персонажей были взяты из публичного доступа.

> [!IMPORTANT]
> Игра представляет из себя **демо-версию** с возможными багами, а также с неполным выбором персонажей (доступны только Крош и Ёжик).

# ⚙️ Техническая часть

Самой интересной частью проекта оказался скорее перенос игры на iOS, нежели её разработка.

Проект разрабатывался в **Clickteam Fusion** и экспортировался в **Xcode-проект**. На этом этапе обычно предполагается, что дальнейшая работа будет происходить в Xcode на Mac.

Технически, условие было выполнено, но полностью средствами GitHub, а конкретнее - с помощью **GitHub Actions**.

## 🔄 Этапы создания

1. Разработка в Clickteam Fusion
2. Билд Xcode-проекта в Clickteam Fusion
3. Создание репозитория из полученного архива на GitHub
4. Загрузка недостающих файлов ([шрифт](https://github.com/Dimarik5/smeshario-ios/blob/main/Resources/Fonts/Smeshariki2007Fixed-Regular.ttf)) и исправление [Info.plist](https://github.com/Dimarik5/smeshario-ios/blob/main/Smeshario_iOS-Info.plist) (для нормального названия приложения и для внедрения шрифта)
5. Написание файла [build.yml](https://github.com/Dimarik5/smeshario-ios/edit/main/.github/workflows/build.yml) с командами по сборке проекта
6. Сборка .ipa файла через GitHub Actions
7. Установка .ipa файла на айфон через SideStore

## 💡 Итог

В результате удалось получить полностью рабочий процесс сборки:

- без собственного Mac
- без ручного запуска Xcode
- только GitHub (GitHub Actions) с облачным Xcode
